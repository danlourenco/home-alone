# Home Alone house

Goal: a faithful, walkable Unity recreation of the McCallister house. Faithfulness is non-negotiable; do not propose "good enough" geometry.

- **Current state and next step (read first):** [docs/RESUME.md](docs/RESUME.md) (Oct 19 queue, job briefs, neighbourhood plan), then [docs/STATUS.md](docs/STATUS.md).
- **Every departure from measurement** (stretches, assumptions, authored sizes) goes in [docs/DEVIATIONS.md](docs/DEVIATIONS.md) with its size and how to revisit it. The house must feel authentic: a room of notably different shape or size than Marina's is not acceptable.
- **How the house gets built:** [docs/RECONCILIATION.md](docs/RECONCILIATION.md). Experiment log: [tasks/sfm-plan.md](tasks/sfm-plan.md).
- **Scale the players, not the house:** true-scale house; Kevin is a kid-sized body (can hide under beds), bandits are adults.
- **Engine:** Unity only (`unity/HomeAlone`, Unity 6000.6.0f1, HDRP). The old Godot prototype was removed Oct 19 (git history has it).
- **Every shadow/lighting/performance change gets a visual + FPS comparison** (user, Oct 20, after the resolution A/B): run it as a `-perfab` tour with the change as a variant (`perf_probe.sh run LABEL`, which writes and opens the sheet automatically: pose rows x variant columns, FPS on every tile; `perf_probe.sh sheet LABEL` to remake it), so the user weighs the look against the FPS. Report in FPS (ms beside it, since ms add up).
- **One test board, not loose sheets** (user, Oct 21: 'so many sheets that have opened it's hard to know what's what'): every comparison sheet goes into `spec/captures/test-board.json` (status, what changed, what to look at, when, commands, images); `tools/house/test_board.py` builds it and it is published to https://claude.ai/artifact/8aAafQn6fGkqvhxncCKB79. Don't open sheets in Preview (`perf_probe.sh` opens only with HA_OPEN=1).
- **Walk notes get a disposition** (Oct 20: a French-window note was lost): after handling or queueing any M note, `python3 tools/house/walk_notes.py set TIME fixed|open|queued|wontfix|info "what"`; `walk_notes.py` (session start, preflight) lists any note with none, `walk_notes.py open` the backlog.
- **Unity 6 best practices for anything generated** (user, Oct 20): shared materials (vary with MaterialPropertyBlock; stay SRP Batcher / GPU Resident Drawer friendly), alpha-clipped HDRP Lit or foliage diffusion profile for vegetation, LODGroups on repeated pieces, instancing over unique combined meshes unless measured cheaper, probes/APV for small props, simple colliders, HDRP mask maps and screen-sized textures, no deprecated APIs (compile clean of warnings: csc_check.sh). Note any departure in the report.
- **Method:** geometry comes from structure-from-motion on Marina Coates's tour videos (repo root `*.mp4`, 1080p copies), not hand-picked landmarks. Tooling in `tools/sfm/`; regenerable outputs in `sfm-work/` (gitignored). Python via `uv run --with numpy --with matplotlib python -I ...`; COLMAP is Homebrew 4.2.1, CPU only.
- **Verification:** a dimension isn't accepted without a re-runnable script, a spread, and a check on held-out views. Never average conflicting sources; log deviations.
- **Plan changes:** after any edit to a trace, doors file, room measurement or the reconciler, run the `verify-plan` skill (`.claude/skills/verify-plan/SKILL.md`; `tools/house/verify_plan.py`). 0 FAIL before building the grey-box. Every fixed tracing mistake adds a proven checkpoint.
- **Geometry changes (either model):** follow the `change-gate` skill (`.claude/skills/change-gate/SKILL.md`). Write the record first. At least one agreeing check must share no data, scale or upstream with the number. Look at before/after renders. Report the change as a TRIAL until the user walks it. The pre-commit hook enforces this (`git config core.hooksPath .githooks` once per clone).
- Evidence and source weights: `art/home_alone/references/` (see `dimensional-baseline/SOURCE_WEIGHTS.md`).
- **Props/furniture dressing:** use `tools/house/props.py` (find, add, front, pin; live in the open editor, no build): change-gate skill "Props in 5 minutes".
- **Slow jobs:** `tools/house/slow_jobs.py` (run at session start by `.claude/settings.json`, and in preflight) flags recurring slow work and builds since the last bake. When it flags a job kind, propose the tool that removes the slowness before running another job of that kind. Log every agent job when it hands back: `python3 tools/house/slow_jobs.py log --kind prop|fixture|tool|search|render --job NAME --s SECONDS --tools N`. When launching one, record it: `python3 tools/house/slow_jobs.py start --kind KIND --job NAME` (the status line shows `slow_jobs.py eta`: elapsed vs the kind's past median).
- **Shared tree, one builder (Oct 18 lessons):** run building jobs one at a time; parallel agents only prepare. Check for a running build with `tools/house/pipeline_busy.sh` (never an inline pgrep: a wait loop matches itself). Never edit `spec/` or models while a build runs (a mid-build edit broke a build). Stage and commit only your own paths. Keep ≥15 GB free (preflight enforces); delete render frames after encoding. If the user is walking, make live changes only: never restart Play or reload the scene.
- **Live evals are read-only on scene objects except the one thing being previewed** (Oct 19: a capture eval added HDAdditionalCameraData to 839 exterior objects, Unity gave each a Camera, and the user's editor froze in Play). Use `unity_pipeline.sh shot|cam` (a camera clone) for captures; never AddComponent/GetComponent-or-add across a hierarchy.
- **Moved or turned anything? Render it from the built output before saying it's done** (Oct 19: a chair turn threw the den chair 18 m outside; the build's walk test showed a new BLOCKED den line and it was waved off as "probably the chair angle"). A walk-test BLOCKED line that HEAD doesn't have is a failure until a render explains it. Generators assert each piece stays in its spec box (hifi_den_props.py does).
- **Every fix gets a before/after comparison** (user, Oct 19): preserve the failing result before changing it. For visible fixes, render the same camera, framing and lighting before and after, including the walk-note pose when available; inspect both and provide a side-by-side comparison. State whether captures are batch or live and disclose differences that limit comparison. For nonvisual fixes, show the same failing check before and passing check after. Comparisons supplement the verification gates; they do not replace them.
- **Static pieces can't be moved live in Play** (static batching: the transform changes, the screen doesn't, and the eval still reports success). Hide the batched renderer and show a copy, then confirm with `unity_pipeline.sh shot`; never report a live fix without that shot.
- **Live preview first:** for colour, material, light and placement tweaks, change the live editor (editor eval / `props.py refresh`), capture, compare with the film, then write the same values into code so the next build keeps them.

## Skills (any agent, including Codex: read the file before the matching job)
Plain instruction files in `.claude/skills/<name>/SKILL.md`; Claude loads them automatically, other agents must open them.
- `change-gate`: before ANY geometry change (walls, rooms, doors, stairs, furniture, fixtures); props/decorations lane and "Props in 5 minutes".
- `verify-plan`: after any edit to a trace, doors file, room measurement or the reconciler.
- `room-upgrade`: any visual upgrade of a room (models, trim, textures, props, lighting); its "Traps" list.
- `artist-pipeline`: generated models (doors, windows, arches, mouldings, cabinets, built-ins) to near-AAA quality.
- `door-assembly`: before building, upgrading or verifying any doorway; one cohesive frame/leaf/finish/collision assembly, inside and outside carpentry checks.
- `zfight-check`: before handing over any visible-surface change (z-fight, clash, stale models).
- `room-feel`: when a room feels too big or small, before moving a wall.
- `overhead-floor`: calibrating Marina's overhead render into a floor plan.
- `anatomy`, `anatomy-reveal`: explanatory SVG/object pages (artifacts), not house work.
